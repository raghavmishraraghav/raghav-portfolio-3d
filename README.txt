📌 Project Overview

A premium, responsive, and interactive personal portfolio website designed to showcase my profile, technical skills, projects, qualification, internship experience, and contact information.

The website uses a dark cinematic visual style combined with modern CSS animations, 3D effects, mouse interactions, responsive layouts, and interactive project cards to create a professional portfolio experience.

⚙️ Run Locally

1. Clone the repository

cd raghav-portfolio-3d

2. Open the project

The portfolio is a static website, so no package installation is required.

You can open:

index.html

directly in a browser.

For development, you can also use the Live Server extension in VS Code.
